About my website

Welcome! This website is a responsive web design project built using modern HTML5 and pure CSS3 without any external libraries or JavaScript frameworks.

Responsive Design

Features fluid column breakpoints that adapt automatically for Mobile (1 column), Tablet (2 columns), and Desktop screens (3 columns).

Pure CSS Features

Includes pure CSS-only interactive elements like openable Modal windows and automatic system Dark Mode adaptation.

Component Library

Offers a structured collection of reusable UI components like forms, custom buttons, alert notifications, and data tables.
